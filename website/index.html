CI/CD Pipeline Flow

Fully automated from commit to deployment

01

Code Push

Developer pushes code to GitHub repository. Webhook is triggered instantly.

02

Jenkins Build

Jenkins detects the webhook, pulls the latest code, and starts the build pipeline.

03

Testing

Automated tests run to validate code quality and functionality before deployment.

04

Ansible Deploy

Ansible playbook copies files to /var/www/html and restarts Apache2 automatically.

05

Live Website

Website is live! Build status notification sent. Total time: under 60 seconds.
