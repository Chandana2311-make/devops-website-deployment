  ABSTRACT (300–400 words)
══════════════════════════════════════════════════

  In modern software development, the ability to rapidly and reliably
  deploy code changes is a critical competitive advantage. This project
  implements an automated Continuous Integration and Continuous
  Deployment (CI/CD) pipeline for website deployment using Jenkins and
  Ansible on Ubuntu Linux.

  The system automates the complete software delivery lifecycle: from
  the moment a developer pushes code to a GitHub repository, through
  automated testing and validation, to deployment on an Apache web
  server — without any manual intervention. The pipeline leverages
  Jenkins as the CI/CD orchestration engine and Ansible as the
  configuration management and deployment automation tool.

  GitHub webhooks provide instant notification to Jenkins upon code
  push, triggering a five-stage pipeline: code checkout, validation,
  testing, Ansible-driven deployment, and verification. Ansible uses
  SSH key-based passwordless authentication to securely connect to
  the deployment server, copies website files to the Apache web root
  (/var/www/html), and automatically restarts the web service.

  The project demonstrates deployment across multiple environments
  including local VirtualBox VMs, AWS EC2, and Azure VMs. Advanced
  features including Docker containerization, multi-server deployment,
  and automated rollback strategies are also implemented.

  The result is a fully automated, repeatable, and auditable deployment
  pipeline that reduces deployment time from 15 minutes (manual) to
  under 60 seconds, eliminates human error, and provides complete
  audit trails through Jenkins build logs.

  Keywords: CI/CD, DevOps, Jenkins, Ansible, Apache, GitHub Webhooks,
  Automation, Configuration Management, Agentless Deployment
